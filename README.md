# AppUsageR-D

## 실행 방법

1. 저장소를 클론합니다:

```bash
git clone https://github.com/0minKoh/AppUsageRND
```

2. Android Studio에서 프로젝트를 엽니다:

- `File` > `Open...`을 클릭하고 클론한 저장소의 디렉토리를 선택합니다.

3. 필요한 종속성을 다운로드합니다:

- Android Studio가 자동으로 종속성을 다운로드하고 프로젝트를 동기화합니다.

4. 에뮬레이터 또는 실제 디바이스를 설정합니다:

- `AVD Manager`를 사용하여 에뮬레이터를 설정하거나 USB 디버깅을 활성화한 실제 디바이스를 연결합니다.

5. 앱을 실행합니다:

- `Run` > `Run 'app'`을 클릭하여 앱을 실행합니다.

이제 앱이 에뮬레이터 또는 연결된 디바이스에서 실행됩니다.

## 주요 폴더

- **app**: 이 폴더는 애플리케이션의 소스 코드와 리소스를 포함합니다. 여기에는 Java/Kotlin 소스 파일, XML 레이아웃 파일, 이미지 리소스 등이 포함됩니다.
- **gradle**: 이 폴더는 Gradle 빌드 시스템과 관련된 파일을 포함합니다. 프로젝트의 빌드 설정을 관리합니다.
- **.idea**: 이 폴더는 Android Studio와 관련된 프로젝트 설정 파일을 포함합니다. IDE 설정, 코드 스타일, 실행 구성 등이 저장됩니다.
- **build**: 이 폴더는 프로젝트의 빌드 결과물이 저장되는 디렉토리입니다. 컴파일된 코드, APK 파일 등이 포함됩니다.
- **libs**: 이 폴더는 프로젝트에서 사용하는 외부 라이브러리 파일을 포함합니다.
- **src**: 이 폴더는 애플리케이션의 소스 코드가 위치하는 디렉토리입니다. 주로 `main`과 `test` 디렉토리로 나뉩니다.
  - **main**: 애플리케이션의 실제 소스 코드와 리소스가 포함됩니다.
  - **test**: 단위 테스트 코드가 포함됩니다.
- **res**: 이 폴더는 애플리케이션의 리소스 파일을 포함합니다. 레이아웃, 문자열, 이미지 등이 포함됩니다.
- **manifest**: 이 폴더는 애플리케이션의 매니페스트 파일을 포함합니다. 애플리케이션의 구성 요소, 권한 등을 정의합니다.
